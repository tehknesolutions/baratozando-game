# V3-02 Visual Gate

Do not call V3-02 complete until runtime evidence confirms all of the following in the complete Cellar:

- canonical premium roach is visible at the centralized world scale;
- full body silhouette remains readable;
- legs, antennae and wings are not visually cropped by normal gameplay framing;
- roach reads as small relative to human-scale Cellar props;
- camera still supports platforming precision;
- no scene overrides the canonical scale;
- walk/run/jump/fall/wing states do not visibly jump in size between frames.

If visual inspection rejects 0.25, change the single `worldScale` value and document the evidence. Never compensate with per-scene scale overrides.
