# M0 Playtest — Cockroach Movement Lab

## Objetivo

Validar se mover a barata já é divertido antes de introduzir combate ou Adaptação.

## Checklist manual

- [ ] A caminhada começa e para sem sensação de gelo.
- [ ] Correr com Shift é claramente mais rápido que andar.
- [ ] Trocar de direção não parece escorregadio.
- [ ] Toque curto e pressão longa no Space produzem alturas distintas.
- [ ] O coyote jump funciona logo após sair de uma borda.
- [ ] O jump buffer funciona quando Space é pressionado pouco antes de aterrissar.
- [ ] Segurar Space não gera saltos automáticos extras.
- [ ] Dodge encadeia naturalmente com corrida e salto.
- [ ] Tentar dodge durante cooldown não congela movimento normal.
- [ ] O hazard remove apenas 1 HP durante a janela de proteção.
- [ ] Após 3 hits, death → respawn restaura 3 HP e limpa velocidade.
- [ ] Checkpoint altera o ponto de respawn.
- [ ] Câmera acompanha sem jitter perceptível.
- [ ] Plataformas continuam legíveis apesar do fundo dark/fog.
- [ ] O percurso inteiro pode ser concluído sem usar R.

## Pergunta de aprovação

Depois de 3–5 minutos sem inimigos: **é gostoso simplesmente correr, pular e escapar como essa barata?**

Se a resposta não for claramente sim, M1 não começa; primeiro ajustamos aceleração, velocidade, salto, dodge ou câmera.
